たしかめーる (TashikaMail) - 見積書・請求書メール送信前チェックアプリ
====================================================================

■ このアプリは何をするもの？
見積書や請求書をメールで送る直前の不安（添付忘れ、別の会社への誤送信、
本文と添付の金額の食い違い、古い版のファイルの添付、相手の国で文字化け
するファイル名）を、送信前にチェックするデスクトップアプリです
（Windows / Mac 両対応）。

送ろうとしているメールの「宛先・件名・本文」と「添付ファイル」をこの
アプリに放り込むと、本文と添付の中身から金額・日付・会社名・文書番号を
抜き出して突き合わせ、結果を信号色で表示します。
　緑＝問題なし／黄＝注意／赤＝止めた方がいい
各検査には理由と根拠（本文の値 vs 添付の値など）が並びます。

■ 大事なこと
・このアプリはメールを送信しません。送信機能そのものがありません。
　結果を見て、実際に送るかどうかは人が自分のメールソフトで決めます。
・インターネット接続なしで動きます。外部にデータを送信しません。
・照合は「正規化した後に完全一致」だけです。似ている名前を候補にする
　曖昧な（ファジー）照合は一切しません。

■ 使い方
1. 宛先メールアドレス、件名、本文を入力します。
   - .emlファイルをドロップ（または「本文/EMLファイルを開く」）すると、
     宛先・件名・本文・添付ファイルを自動で分解して全部セットします。
   - 本文は .txt ファイルからも読み込めます。
2. 添付ファイルをドロップ（または「添付を追加」）します。
   対応形式：PDF、.xlsx、.csv、.txt、.docx、画像（png/jpg/jpeg/tif/
   tiff/bmp/gif/webp）、および .eml の中の添付。
   画像とスキャンPDF（テキスト層のないページ）は内蔵OCRで読み取り
   ます（後述）。
3. 分かる場合は「確認用の正解」に相手先の会社名・期待ドメイン・金額・
   日付・文書番号を入力します。入力した値が最優先の照合基準になります。
4. 相手の国を選び、「検査する」を押します。
5. 結果（信号色・理由・根拠）を見て、送るかどうかを人が決めます。
   ファイル名に問題がある場合は、安全な英数字の名前の提案が表示され、
   ボタンを押したときだけ、その名前でコピーを書き出します。

■ 検査項目
A. 添付忘れ（本文が言及しているのに添付0件＝赤 など）
B. 金額の突き合わせ（合計同士を優先比較。不一致＝赤）
C. 日付の突き合わせ（支払期限・有効期限の食い違い＝赤、その他＝黄）
D. 会社名の突き合わせ（法人格を外して正規化し完全一致のみ）
E. 文書番号（見積番号・請求番号など。不一致＝赤）
F. 宛先ドメインと会社名の食い違い（フリーメールは確認不能＝黄、
   期待ドメインと違う＝赤）
G. 古い版の可能性（ファイル名の日付・版数・下書き語・同じ文書の複数
   添付などを検査）
H. ファイル名の文字化けリスク（相手の国基準。安全なリネーム案を提示）
I. 総合判定（最も悪い項目に合わせて 緑／黄／赤）

■ OCR（文字読み取り）について
・画像添付と、スキャンPDFのテキスト層のないページは、内蔵の
　Tesseract OCR（v5.5.3＋tessdata_fast 13言語）で読み取り、通常の
　添付と同じ抽出・検査にかけます。テキスト層のあるページは従来通り
　テキスト抽出するので、混在したPDFにも対応します。.eml の中の画像
　添付・スキャンPDF添付も同じ扱いです。
・OCRで読んだ添付は、添付リストに「（OCRで読み取り）」と表示され、
　結果にも「OCRで読み取りました」という行と、「OCRで読み取った数字
　は、原本と見比べてください」という注意行が出ます（注意行は助言の
　ため、総合信号色は変えません）。
・解決順：環境変数 TASHIKAMAIL_TESSERACT_CMD の指定 ＞ アプリの隣の
　tesseract フォルダ（同梱版）＞ システムのPATH。OCR言語は日本語＋
　英語＋現在の表示言語です。
・【Macの場合】同梱のTesseractはWindows版プログラムのため、Macでは
　使えません。MacではHomebrewで入れたTesseract
　（/opt/homebrew/bin/tesseract、/usr/local/bin/tesseract）を自動で
　探します。見つからない場合、OCRだけが使えず（画像・スキャンPDFは
　「読み取れなかった」扱いになります）、画面下部に導入方法
　（ターミナルで「brew install tesseract tesseract-lang」）が表示
　されます。それ以外の機能は通常どおり使えます。言語データは同梱の
　tessdataがあればそれを使い、なければTesseract本体のものを
　使います。
・OCR処理は時間がかかるため、「検査する」を押すと裏側で処理し、
　読み取り中のファイル名を表示します。画面は固まりません。

■ 制限（正直な明記）
・OCRは誤読することがあります。特に小さな文字、手書き、傾いた
　スキャン、複雑な表では読み間違いが増えます。本アプリはOCRで読ん
　だ数字をそのまま照合に使うため、結果画面の注意行の通り、数字は
　必ず原本と見比べてください。
・OCRでも読み取れなかった添付は「読み取れなかった＝注意（黄）」と
　して表示し、緑にはしません。中身は人が確認してください。
・金額や日付は、本文・添付に書かれた表記からの抽出です。書式が大きく
　崩れた文書では抜き出せない場合があり、その場合は「確認できません
　でした」という注意表示になります。
・ドメインと会社名の照合は、英字化できる会社名の範囲で行います。
　日本語のみの会社名ではドメイン確認ができないため注意表示になります。
・グループ会社など、ドメインと会社名が一致しない正当な場合もあります。
　そのためFの不一致は（期待ドメインを入力した場合を除き）断定せず
　「食い違いの可能性」として黄で表示します。

■ 起動方法（Windows・ソース版）
・同梱の Start-TashikaMail.bat をダブルクリックしてください。
　（初回だけ必要なライブラリを自動で入れます）
・手動の場合：python app.py
　必要なライブラリは requirements.txt の通りです。

■ 起動方法（Mac・ソース版）
・同梱の Start-TashikaMail.command をダブルクリックしてください。
　初回だけ、このフォルダの中に専用のPython環境（.venv-mac）を
　自動で作り、必要なライブラリを入れます。
・Macに Python 3 が入っていない場合は、その旨と入手方法
　（python.org のインストーラ、または Homebrew の
　「brew install python」）が表示されて終了します。
・手動の場合：python3 app.py
　必要なライブラリは requirements.txt の通りです。

■ Mac用アプリ（.app）の作り方
1. このZIPをダウンロードして展開します。
2. 展開したフォルダの中の MakeApp-Mac.command をダブルクリック
　します（初回はライブラリとPyInstallerの導入で少し時間が
　かかります）。
3. 成功すると dist フォルダの中に TashikaMail.app ができます。
　以降はこの .app をダブルクリックするだけで起動できます。
・チップ（CPU）について：まず Intel / Appleシリコン両対応の
　universal2 で作成を試み、環境によって作れない場合は、そのMacの
　チップ専用（ネイティブ）で自動的に作り直します。どちらで作れた
　かは、最後に画面に表示されます。ネイティブ版は、作ったMacと
　同じチップのMacでのみ動きます。
・対応OS：macOS 11（Big Sur）以降です。
・このアプリは未署名のため、初回起動時にGatekeeperの確認が出ます。
　TashikaMail.app を右クリックして「開く」を選んでください。
・Mac版は開発環境にMac実機がないため、実機での動作確認は未実施
　です。Windows版と同じソースコードで動作します。

■ 表示言語
日本語・English・Español・简体中文・Français・Deutsch・Português・
Русский・Italiano・Türkçe・العربية・Bahasa Indonesia・한국어 の13言語。
画面右上の切替で即時に切り替わり、選択は保存されます。
タイトルは日本語UIでは「たしかめーる」、他の言語では「TashikaMail」
と表示されます。
