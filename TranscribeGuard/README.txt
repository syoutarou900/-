転記見守り君 (TranscribeGuard)
================================================

※アプリ名は「転記見守り君」です。英語の
TranscribeGuard はファイル名用の英字名です。

これは何をするアプリ？
------------------------------------------------
請求書や注文書を見ながら、Excelや会社のシステムへ手で打ち直す作業を
「見守る」Windows / Mac デスクトップアプリです。完全自動化はしません。
アプリは下準備・照合・チェックまでを行い、最後の転記（会社のシステムへ
入力する作業）は、必ず人自身が行う設計です。

・元ファイル（PDF / Excel / CSV / TXT / 画像）を読み込むと、左側に
  項目ごとに分解して表示します
・右側の入力欄に打ち込むたびに、元の値とその場で照合します
  - 合えば、左の項目が薄くフェードしてチェックが付きます
  - 違えば、赤くなって理由が出ます（数字は「元 ○桁 ／ 入力 ○桁」）
・数字は項目名ごとの合計も照合し、下の表で食い違いを赤く示します
・画面の上に「未入力が○件」と残数が常に出ます
・全部合えば、結果をTSVでコピーしてExcelや会社のシステムに貼れます
  （Excel / CSV での保存、作業の保存・再開もできます）

今回の改良点（高速起動＋OCR内蔵版）
------------------------------------------------
・起動方式を「フォルダー方式」に変え、起動が大幅に速くなりました。
  以前の1ファイル方式は、起動のたびに中身を展開する待ち時間があり
  ましたが、フォルダー方式ではその展開が不要です
・画像からの文字読み取り（OCR）のエンジン「Tesseract」を、EXE版には
  最初から組み込みました。別途インストールは不要です。対応する読み
  取り言語は、画面の13言語と同じ13言語分を同梱しています
  （日本語＋英語が基本で、画面の表示言語に合わせた言語も使います）

EXE版の使い方（フォルダー方式）
------------------------------------------------
1. TranscribeGuard-EXE.zip をダウンロードします（分割されている場合は
   結合用バッチで1つのZIPに戻します）
2. ZIPを「すべて展開」します
3. 出てきた「TranscribeGuard」フォルダーを開き、中の
   TranscribeGuard.exe をダブルクリックします
・このフォルダーは丸ごと1つのアプリです。TranscribeGuard.exe だけを
  フォルダーの外へ移動すると起動できません。_internal フォルダーと
  tesseract フォルダーは、必ず exe と同じ場所に置いてください
・移動したいときは、TranscribeGuard フォルダーごと移動してください

初めての起動手順（Windows・ソース版ZIPの場合）
------------------------------------------------
1. TranscribeGuard-Source.zip をダウンロードします
2. ZIPを「すべて展開」します（展開せずに中のファイルを実行しないで
   ください）
3. 展開したフォルダーを開き、Start-TranscribeGuard.bat を
   ダブルクリックします
4. 初回だけ、必要なライブラリを自動でダウンロード・インストール
   します。黒い画面（コマンド画面）はアプリ使用中は開いたままに
   してください。閉じるとアプリも終了します
5. 2回目以降は数秒で起動します
・ソース版で画像のOCRを使いたい場合は、EXE版に同梱されている
  tesseract フォルダーを、app.py と同じ場所に置くか、Tesseract 本体を
  パソコンにインストールしてください。どちらも無い場合は、画面に
  その旨が表示され、項目を手で追加して使う形になります

Macでの使い方（ソース版ZIPから .app を作る方法）
------------------------------------------------
対応環境は macOS 11（Big Sur）以降です。Mac版は、配布ZIPをダウン
ロードした後、Mac自身でアプリを組み立てる方式です。

1. TranscribeGuard-Source.zip をダウンロードし、ZIPを展開します
2. 展開したフォルダーで MakeApp-Mac.command をダブルクリックします
   （macOSのセキュリティ確認で開けない場合は、ファイルを右クリック
   して「開く」を選びます）
3. Python 3.10以降が無い場合は、画面の案内に従い python.org の
   macOSインストーラー、または Homebrew で Python を入れてから、
   もう一度 MakeApp-Mac.command を実行します
4. 初回だけ、必要なPythonライブラリと PyInstaller を自動でダウン
   ロード・インストールします
5. 完成すると、同じフォルダーの dist の中に TranscribeGuard.app が
   できます。以後はその .app を起動してください

・MakeApp-Mac.command は、まず Intel Mac と Apple Silicon Mac の
  両方で動く universal2 形式を試みます。使っているPythonやライブ
  ラリが universal2 に対応していない場合は、そのMacのチップ専用
  形式で自動的に作り直し、最後にどちらの形式で作れたかを表示します
・この方法で作る .app は Apple の署名がないため、初回起動時に
  Gatekeeper の確認が出ます。Finderで TranscribeGuard.app を
  右クリックし、「開く」を選んで確認してください
・アプリをすぐ試したい場合は、MakeApp-Mac.command の代わりに
  Start-TranscribeGuard.command を使うと、ソース版を直接起動できます

MacでのOCR（Tesseract）について
------------------------------------------------
EXE版に同梱している Tesseract は Windows用バイナリのため、Macでは
使えません。Mac版では次の順番で Tesseract を探します。

1. 環境変数 TRANSCRIBEGUARD_TESSERACT_CMD（または
   TRANSCRIBEGUARD_TESSERACT）で指定された実行ファイル
2. アプリと同じ場所にある macOS用 tesseract
3. Homebrew の標準場所
   ・Apple Silicon: /opt/homebrew/bin/tesseract
   ・Intel Mac: /usr/local/bin/tesseract
4. システムの PATH にある tesseract

見つからない場合、OCRだけが「未導入」として扱われ、画像以外の読み
込み、照合、保存などの機能は通常通り使えます。画像を開いたときは
OCRが見つからない旨が表示されます。MacでOCRを使う場合は、Homebrew
（https://brew.sh/）を入れた後、ターミナルで次を実行してください。

  brew install tesseract tesseract-lang

tesseract-lang は日本語を含む追加言語データです。インストール後に
アプリを再起動してください。

まず試すには
------------------------------------------------
1. アプリを起動します
2. 上部の「サンプルで試す」ボタンを押すと、日本語の請求書サンプルが
   読み込まれます
3. 右側の入力欄に、左の値と同じものを打ち込んでみてください

動作確認キット（自分のデータが無くても試せます）
------------------------------------------------
・Verify-Checklist.txt … 起動から出力までを数分で確認できる
  6項目のチェックリストです。まずこの順番で試してください
・samples/ocr_sample.png … OCR（画像の読み取り）練習用の請求書画像
  です。「ファイルを開く」で開くと、文字が読み取れて項目になります
・samples/sample_invoice.pdf … PDF読み込み練習用の小さな請求書
  PDFです。「ファイルを開く」で開くと項目に分解されます

同梱ファイル（ソース版）
------------------------------------------------
Start-TranscribeGuard.bat … Windows起動用（ダブルクリック）
Start-TranscribeGuard.command … Macでソース版を直接起動する用
MakeApp-Mac.command … Macで TranscribeGuard.app を生成する用
app.py / core.py / i18n.py … アプリ本体
requirements.txt … 必要なライブラリの一覧
README.txt … このファイル
Verify-Checklist.txt … 動作確認チェックリスト
samples/ … 確認用のサンプル（ocr_sample.png / sample_invoice.pdf）

正直な制限
------------------------------------------------
・EXE版のOCRは組み込み済みですが、読み取りの正確さは画像の状態に
  依存します。読み取り結果は必ず目で確認してください。またスキャン
  画像だけのPDFは「画像」として扱われます（PDFとして直接読み込める
  のは、文字データを持つPDFです）
・このアプリは会社のシステムに自動でログインしたり、勝手に入力
  したりはしません。照合結果を会社のシステムへ移すのは人です
・本アプリはLinux上のエミュレーション環境（Wine）での起動確認までで、
  実物のWindowsパソコンでの起動はまだ未検証です。Wine環境での実測
  では、画面が表示されるまで旧版（1ファイル方式）が約120秒だったのに
  対し、今回のフォルダー方式は約14秒でした（実機のWindowsでは環境が
  違うため、この秒数そのものは目安としてお考えください）
・Mac版も実機のMacでの起動確認はまだ未検証です。Mac用スクリプトは
  標準的な Python / PySide6 / PyInstaller の手順で動作するよう作って
  いますが、利用するMacのOSバージョン、Pythonの入手方法、Gatekeeper
  の設定によっては追加の確認操作が必要になる場合があります
・Macで生成される .app は universal2、または組み立てたMacのチップ
  専用形式のどちらかです。専用形式で作られた .app を別のチップの
  Macで使う場合は、そのMacでもう一度 MakeApp-Mac.command を実行
  して作り直してください

対応言語
------------------------------------------------
画面表示は13言語に切り替えできます（日本語・English・Español・
简体中文・Français・Deutsch・Português・Русский・Italiano・Türkçe・
العربية・Bahasa Indonesia・한국어）。
選んだ言語は保存され、作業の途中経過も自動保存されます。
