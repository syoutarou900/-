DropLauncher（ドロップランチャー）

小さなパネルにファイルをドラッグ＆ドロップするだけで、ファイルの仕分けや名前の変更、画像・PDF・動画・Excelの変換、ZIPの圧縮・解凍などを自動で処理します。面倒な設定は不要で、やりたい作業の枠にファイルを入れるだけ。 毎日のパソコン作業の「ちょっとした手間」をまとめて引き受けます。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

バージョン探偵（VersionDetective）

「どれが本当の最新版？」を、ファイルの中身で見分けるアプリ。 フォルダを入れると、内容がまったく同じファイルと、同じ文書の別バージョンらしいファイルをグループにまとめます。最新候補は時系列の系図で表示され、本文の更新日時など根拠も一緒に示します。文章や表の差分も確認可能。古い版を勝手に消すことはなく、承認したファイルだけを保管用フォルダへ移動します（取り消しもできます）。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

UniList（ユニリスト）

顧客・取引先リストの重複を、安全に1件にまとめるアプリ。 名前・電話・メール・住所などの表記をそろえたうえで、完全に一致する重複候補だけを提示します。候補は左右に並べて見比べ、残す項目を選んで、人が承認したものだけを統合。元のファイルは書き換えず、統合の取り消しもできます。あいまいな判定で別の会社を候補に挙げることはありません。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

転記見守り君（TranscribeGuard）

資料からシステムへの転記ミスを、入力しながら防ぐアプリ。 PDF・Excel・画像の元資料を項目に分解して左に並べ、右の入力欄とその場で照合します。転記できた項目は薄く消え、桁数や合計が合わない箇所は赤く警告。最後に「未入力が○件」と表示されるので、写し残しに気づけます。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

たしかめーる／TashikaMail

見積書・請求書メールを送る前の、最終チェックアプリ。 本文と添付ファイルの金額・日付・会社名・文書番号を読み比べて、食い違いがあれば理由と根拠つきで信号機のように表示します。宛先のドメインと会社名の不一致、古い版の添付、文字化けの恐れもチェック。画像添付やスキャンPDFは文字読み取り（OCR）で確認します。送信機能はなく、最後に送る判断は人が行います。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

一回やれば手順書／StepOnce

ふだんの操作を記録するだけで、手順書の下書きができるアプリ。 記録を始めて、いつも通り操作すると、クリックごとに画面の写真を撮り、押したボタンの名前から説明文の下書きを作ります。パスワード入力欄はモザイクの候補として示されます（自動ではかけません）。仕上げた手順書は、PDFとWordで13言語に書き出せます。キーボードで打った内容は記録しません。※Macでは、ボタンを押して記録する手動方式です。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

スクショ安心フィルター／RedactShot

スクリーンショットを共有する前に、見せたくない情報を消すアプリ。 メールアドレス、電話番号、カード番号らしい並び、金額、パスワード欄の候補などを自動で検出し、モザイク・ぼかし・黒塗りで隠します。項目ごとにオン・オフでき、自分で範囲を指定して隠すことも可能。消す強さは「絶対に読めない」レベルに固定されています。元の画像は変更せず、書き出し前に最終確認の画面が出ます。ネットにつながなくても使えます。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

PurePaste（ピュアパステル）

コピーした文章を、その場できれいに整える常駐アプリ。 WebやPDFからコピーしたときに入る変な改行、余分な空白、全角と半角の混在などをコピーした瞬間に自動で整形します。ルールごとにオン・オフでき、一時停止や「元の文に戻す」も可能。トレイに常駐して、ふだんの作業を邪魔しません。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

マッチング探偵／MatchDetective

2つの表のズレを、理由つきで見つける突き合わせアプリ。 自社の表と相手の表を読み込むと、会社名の法人格（株式会社・Inc.など）や表記のゆれをそろえて照合し、結果を「片方にだけある」「金額・数が違う」「表記違いだが同じ相手らしい」の3種類に分けて、理由と確からしさと一緒に提示します。あいまいな推測では候補に挙げないので、別の会社を取り違える心配がありません。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

フォーマットパスポート／FormatPassport

国ごとに違う「書き方の形式」を、相手の国の形式に変換するアプリ。 日付の並び順、小数点と桁区切り、CSVの区切り文字、文字コード、全角・半角、和暦と西暦などを、送り手と受け手の国に合わせて変換し、変換前と後を並べて確認できます。「03/04」のような曖昧な表記は自動で変えず、要確認リストに残します。金額の通貨換算も、中央銀行などの公式レートで行えます。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。

ContextStruct（コンテキスト・ストラクト）

バラバラな資料を、表の形に整理するアプリ。 FAXのPDF、スキャンした納品書、取引先のWebカタログなど、形式の決まっていない資料を読み取り、品名・数量・単価・金額などを項目として抜き出して表にします。読み取りの確からしさは色で表示され、その場で直すことも可能。Excel・CSV・JSONで書き出せます。読み取りAIはパソコンの中で動くため、ネットにつながなくても使えます。

GlobalHours（グローバルアワーズ）

世界中の取引先の「今の営業時間」が、ひと目で分かるアプリ。 取引先の国と都市を登録しておくと、自分の日時に対して相手が何時で、営業時間内か、週末か、祝日かが、24時間の帯の並びで一目で分かります。双方の営業時間に収まる候補も提示し、相手の言語でそのまま使える提案文も作れます。送信は自分で行う形で、送信機能はありません。

アプリをダウンロード (Windows用) 対応OS: Windows 11 / 10 (64bit) アプリをダウンロード (Mac用) macOS 11以降。Intel製とApple Siliconの両チップ対応です。
