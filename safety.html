安全への取り組み

最終更新日：2026年11月22日

「安全です」と言うだけではなく、あなた自身が確かめられる形にしています。

このページの要点

  • 全アプリをVirusTotalで検査済みです（71社すべて検出なし）
  • ソースコードをGitHubで公開中です（中身を自分で確認できます）

5コード署名について（正直な説明）

大手企業のアプリには「コード署名」という、開発者を証明する仕組みが付いていることが多く、その場合は警告が出ません。

このサイトのアプリに署名が付いていないのは、署名用の証明書が個人には高額で、無料配布の範囲ではまかなうのが難しいためです。署名がない代わりに、公開前のVirusTotal検査と結果の公開、SHA-256による真正確認の手段を用意しています。

現在の進み具合：オープンソース向けの無料署名プログラム「SignPath Foundation」への申請は、まだ提出していません。署名の申請は、すべての準備が整ってから最後に行います。進展があり次第、本ページでお知らせします。

6データの扱い

アプリがあなたのデータを収集することはありません。処理は原則としてパソコンの中で完結しますが、一部の機能を使うときだけインターネットと通信します。詳しくはプライバシーポリシーをご覧ください。

チップのお支払いはKo-fiを通じて受け付けており、決済はStripeまたはPayPalが処理します。本サイト自体が、カード情報を取得・保持することはありません。評価・感想フォーム（Tally）で送信された内容の扱いについても、プライバシーポリシーをご覧ください。

プライバシーポリシーデータの取り扱いについて利用条件無料で使うための条件免責事項ご利用の前に知ってほしいこと安全への取り組み検査と確認の仕組み

Last updated: November 22, 2026

Rather than just saying "safe", everything is set up so you can verify it yourself.

Key points

  • Every app is scanned on VirusTotal before release (no detections by all 71 engines)
  • The source code is published on GitHub, so you can read what is inside
  • SHA-256 values let you verify that your download is genuine

5About code signing (an honest explanation)

Apps from large companies often carry "code signing", a certificate that proves the developer's identity, and no warning appears for them.

The apps on this site are unsigned because signing certificates are expensive for an individual, and difficult to cover while distributing the apps for free. Instead of a signature, we provide a VirusTotal scan and published results before release, plus SHA-256 values so you can verify your download.

Current status: we have not yet submitted an application to SignPath Foundation, a free signing program for open-source projects. The signing application will be made last, once all other preparations are complete. Updates will be announced on this page.
