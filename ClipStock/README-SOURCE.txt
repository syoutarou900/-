ClipStock - Source Code (version 1.0.0)
============================================================
This ZIP contains the full source code of ClipStock, published so that
anyone can inspect what the app does, or build it themselves.
マルウェアやスパイウェアの類は含まれていません。中身を自由にご確認ください。


- Python 3.11 or later
- pip install -r requirements.txt


- Windows: Start-ClipStock.bat (or: python app.py)
- Mac: Start-ClipStock.command (or: python3 app.py)


- Windows (.exe): MakeExe-*.bat (uses PyInstaller) — if included
- Mac (.app): MakeApp-Mac.command

Notes:
コピー履歴はこのパソコンの中だけに保存され、アプリが通信することは一切ありません。カード番号のような形式のテキストは、初期設定では履歴に保存されません。
Clipboard history is stored only on this computer, and the app makes no network connections. Card-number-like text is not saved to history by default.
