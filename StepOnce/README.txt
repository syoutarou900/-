一回やれば手順書 / StepOnce  v1.0.0
============================================================

※名前について：正式名は「StepOnce」（日本語名：一回やれば手順書）
です（2026-11-15決定）。なお「ManualMaker」という名は既存のiOS
アプリ（同種のマニュアル作成アプリ）が使っているため使いません。

これは何をするアプリ？
------------------------------------------------------------
引き継ぎや新人教育のたびに、画面写真を撮って、切り取って、
説明文を書く手順書づくりには何時間もかかります。このアプリは、
「記録開始」を押してふだん通りに操作するだけで、クリックごとに
画面写真を撮り、押したボタンの名前から説明文の下書きを自動で
付けます。人がステップ一覧で文章を直して確定すると、その内容で
13言語版の手順書（PDF・Word）を出力します。

半自動の原則：アプリがやるのは下書きと候補の提示までです。
内容の確定と出力は、必ず人が行います。

大事なプライバシー仕様
------------------------------------------------------------
・キーボードで打った文字は記録しません。記録するのは「入力欄を
　クリックした」という事実と、その欄の名前だけです。
・パスワード欄らしい部分は、モザイクの「候補」として示します。
　自動でモザイクはかかりません。候補を見て、人が「適用」か
　「却下」を選んでください。
・記録はこのアプリの中だけに保存されます。どこかへ送信される
　ことはありません（下記の任意の翻訳機能を使った場合を除く）。

使い方
------------------------------------------------------------
1) Windowsの場合：StepOnce.exe を起動します（ソース版は
　Start-StepOnce.bat）。
   Macの場合：先に「Macでの使い方」を見てください。
2) 手順書のタイトルを入力します。
3) 「● 記録開始」を押します。小さな記録パネルが出ます。
   - Windows：そのまま対象のアプリをふだん通りに操作してください。
     クリックのたびに自動でステップが追加されます。
   - Mac：手動キャプチャ方式です。操作の節目ごとに、記録パネルの
     「今の画面を追加」ボタン（または F8 キー）で画面を追加します。
4) 記録パネルの「終了」か、本体の「■ 記録を止める」で記録を終えます。
5) ステップ一覧で内容を整えます：
   - 説明文の下書きを直す（直した文章は自由文になります）
   - メモを付ける、並べ替える、削除・複製する
   - モザイク候補を適用/却下する、画像をドラッグしてモザイクを
     追加する（「モザイク追加モード」をオンにして画像上をドラッグ）
   - 画像ファイルからステップを追加することもできます
6) 「プロジェクトを保存」で保存します（フォルダ形式）。
   ZIPで書き出す/読み込むこともできます。
7) 「手順書を書き出す」で、言語（13言語から選択）と形式
   （PDF / Word）を選んで書き出します。言語ごとに1ファイルずつ
   出力されます。

13言語化の仕組み（正直な説明）
------------------------------------------------------------
・下書きの定型文（『○○ボタンをクリックします』など）と手順書の
　体裁文（表紙・目次・「ステップN」・注記）は、13言語すべてに
　翻訳済みの文面をアプリ内に持っています。
・ボタン名などの対象名は、記録した原文のまま差し込まれます。
・人が自分で書いた文章（説明文の書き直しとメモ）は翻訳されません。
　各言語版にも原文のまま入り、手順書にはその旨の注記が付きます。
・任意機能：設定で自分の DeepL API キーを入れると、書き出しの
　ときに自由文の機械翻訳を使うか選べます。キーが無い場合は
　完全にオフラインで動きます。翻訳に失敗した文章は原文のまま
　出力され、結果画面にその旨が表示されます。アラビア語は
　DeepL の対象外のため、常に原文のまま出力されます。

Macでの使い方
------------------------------------------------------------
Mac版はソース版からアプリを組み立てる方式です：
1) StepOnce-Source.zip を展開します。
2) MakeApp-Mac.command をダブルクリックします
　（初回は右クリック→「開く」が必要な場合があります）。
3) dist フォルダに StepOnce.app ができます。以後はそれを
　ダブルクリックして使います（初回起動も右クリック→「開く」）。
・対応：macOS 11 以降。チップは universal2（Apple Silicon＋Intel
　両対応）をまず試し、作れない場合はそのMac専用のアプリになります。
・Macでは自動クリック記録は行いません。自動記録には macOS の
　アクセシビリティ許可と専用の実装が必要で、実機検証ができない
　ため、手動キャプチャ方式を正式な方式としています。
・画面の撮影には「画面収録」の許可が必要な場合があります。

制限と正直な注意点
------------------------------------------------------------
・実Windowsでの自動記録の動作、および実Macでの動作は未検証です
　（開発環境でのテストと Wine 上の起動確認までを実施しています）。
・管理者権限で動いているウィンドウでは、要素の名前が取れない
　場合があります。その場合は汎用の下書き文になります。
・ゲーム画面、動画、リモートデスクトップの中の画面など、UI情報が
　無い画面では名前が取れません（画面写真と汎用文だけになります）。
・このアプリ自身の画面のクリックは記録されません（記録パネルの
　ボタンをステップにしないため）。
・記録されるのはマウスの左クリックだけです。右クリックや
　キーボード操作、ドラッグはステップになりません。

言語の切り替え
------------------------------------------------------------
画面上部のヘッダー右端にある言語コンボボックスで、13言語を
再起動なしで即時に切り替えられます。選んだ言語は保存され、
次回起動時も維持されます。アラビア語を選ぶと画面全体が
右から左のレイアウトになります。記録パネルも同じ言語になります。

動作環境
------------------------------------------------------------
・Windows 10 / 11（64ビット）：EXE版（Python不要）
・macOS 11 以降：ソース版から .app を生成
・ソース版の実行には Python 3 が必要です（PySide6 と Pillow を
　初回起動時に自動でインストールします）
