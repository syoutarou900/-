StepOnce - Source Code (version 1.0.0)
============================================================
This ZIP contains the full source code of StepOnce, published so that
anyone can inspect what the app does, or build it themselves.
マルウェアやスパイウェアの類は含まれていません。中身を自由にご確認ください。


- Python 3.11 or later
- pip install -r requirements.txt


- Windows: Start-StepOnce.bat (or: python app.py)
- Mac: Start-StepOnce.command (or: python3 app.py)


- Windows (.exe): MakeExe-*.bat (uses PyInstaller) — if included
- Mac (.app): MakeApp-Mac.command

Notes:
DeepL翻訳を使う場合は、ご自身のDeepL APIキーを設定画面で入力してください（キー自体はソースに含まれていません）。Windows版はクリックを自動記録し、Mac版は手動キャプチャ方式です。
To use DeepL translation, enter your own DeepL API key in the settings (no key is included in the source). The Windows version records clicks automatically; the Mac version uses manual capture.
