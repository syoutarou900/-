マッチング探偵 / MatchDetective
================================

2つの表（発注リストと納品リスト、請求一覧と入金一覧、在庫表と棚卸し表など）を
照合（reconciliation）して、違いだけを3つの区分で見せるアプリです。

  1. 片方にだけある
  2. 金額・数が違う
  3. 表記違いだが同じ相手らしい（理由付きの候補）

会社名の法人格（株式会社 / (株) / Ltd. / GmbH / ООО / PT など、13言語分）や
表記のゆれ、全角・桁区切りなどの違いを吸収して比べます。
区分3の候補は、正規化したら完全に一致するものと、合計が完全に一致する
ものだけです。「よく似ている」という理由だけで候補に出すことはありません
（似ているだけの名前は区分1に出ます。同じ相手なら手動で組にできます）。
1件の請求を分けて払ったような「数件の合計が一致」する候補も提示します。
アプリは提案までを行い、採用・却下の最終判断は人が行います。
元のファイルを変更することはありません。

使い方
------
1. 表Aと表Bに、比べたい CSV / Excel ファイルをドラッグ＆ドロップ
   （またはボタンから開く）
2. キー列と比較列はアプリが提案します。必要ならプルダウンで変更できます。
   列名を直接タイプして指定することもできます（全角・空白・記号の違いや
   「オーダーNo」のような別名でも、該当する列として認識します。
   見つからない名前を入力した場合は、赤枠とメッセージでお知らせします）
3. 「照合する」を押すと、違いが3区分で表示されます
4. 区分3の候補は「採用する」「却下する」で判断してください
5. 結果は Excel / CSV / レポート(txt) に書き出せます

会社名の辞書（学習機能）
------------------------
漢字とカタカナのように表記が大きく違う会社名は、自動では同一と判断
しません（違う会社を候補に出さないためです）。代わりに、人が一度
「同じ会社」と確定した組み合わせを辞書に覚え、次回から自動で組に
します。
- 区分1で両側の行を選んで「同じ会社として登録」
- 手動で組にする際も、確認ダイアログで辞書登録を選べます
  （チェックは最初から入っています）
- 「辞書を管理」から一覧・削除・手入力での追加ができます
辞書は Windows では %APPDATA%\MatchDetective\aliases.json、Mac では
~/Library/Application Support/MatchDetective/aliases.json に保存されます。
削除は次回の照合から効きます（表示中の結果は変わりません）。

法人番号での確認（日本の会社のみ）
----------------------------------
設定欄に国税庁の無料のアプリケーションIDを入れると、区分1の会社名を
国税庁の法人番号登録で確認できます。
- 「法人番号で確認」：選んだ会社名の登録情報（商号・フリガナ・
  法人番号・住所）を判断材料として表示します
- 「法人番号で自動照合」：登録が1社だけで、カタカナ表記の読みが
  登録フリガナと完全に一致する場合に限り、自動で組にします。
  同名の法人が複数ある場合は自動では組にせず、一覧から人が選びます
- 「WEBで確認」：会社名の検索をブラウザで開きます（公式サイトの
  確認は人が行います。アプリが会社サイトを自動で調べることは
  ありません）
- 選んだ法人で「登録して組にする」と、法人番号つきで辞書に登録
  されます
取得した登録情報は Windows では %APPDATA%\MatchDetective\houjin_cache.json、
Mac では ~/Library/Application Support/MatchDetective/houjin_cache.json に
キャッシュされ、画面にデータ基準日と取得日を表示します。
IDの発行申請は国税庁のページから行えます（無料、2週間〜1か月程度）。
このサービスは、国税庁法人番号システムのWeb-API機能を利用して取得
した情報をもとに作成しているが、サービスの内容は国税庁によって
保証されたものではない

起動（ソース版）
----------------
- EXE版：MatchDetective.exe をダブルクリック
- ソース版：Start-MatchDetective.bat をダブルクリック
  （初回だけ Python ライブラリを自動で入れます。2回目からは速く起動します。
   黒い画面はアプリを閉じるまで開いたままにしてください）

Mac版について
--------------
対応は macOS 11（Big Sur）以降です。Mac版のアプリ本体（.app）は、
Macの上で組み立てる決まりのため、ダウンロードしたZIPには
「組み立てスクリプト」を同梱しています（Windows版と同じプログラムです）。

  1. ZIPをダウンロードして展開する
  2. MakeApp-Mac.command をダブルクリックする
     （「開発元を確認できないため開けません」と出た場合は、
       MakeApp-Mac.command を右クリック（または Control+クリック）して
       「開く」を選んでください。初回だけ必要な操作です）
     Python 3 が無い場合は、スクリプトが入手方法（python.org の
     インストーラ等）を案内して終了します
  3. dist フォルダに MatchDetective.app ができます。好きな場所へ
     移動して使ってください。初回起動時も同じ理由で、アプリを
     右クリックして「開く」を選ぶ必要があります（未署名のため）

- チップ（CPU）について：スクリプトはまず、Apple Silicon と Intel の
  両方で動く「universal2」版の生成を試みます。お使いの Python の
  都合で作れない場合は、そのMacのチップ専用版を自動で作り直し、
  どちらができたかを最後に画面で知らせます
- Python をすでにお持ちの方は、Start-MatchDetective.command を
  ダブルクリックすれば .app を作らずにそのまま起動もできます
- 正直な注意：開発環境に Mac 実機がないため、Mac での起動は
  未検証です。Windows版は従来どおり検証済みです

対応形式：CSV（区切り文字・文字コードは自動判定）、.xlsx / .xlsm
対応言語：日本語・English・Español・简体中文・Français・Deutsch・Português・
Русский・Italiano・Türkçe・العربية・Bahasa Indonesia・한국어

注意
----
- 「似ている名前」を自動で組にすることはありません。違う会社を候補に
  出して間違いの元にならないよう、候補は完全一致（正規化後）と合計一致
  だけに限っています。最終確認は必ず人が行ってください。
- 法人番号での自動照合は日本の会社だけが対象で、アプリケーションIDが
  必要です。漢字とカタカナが混ざった表記（例：田中デンキ）は法人番号
  でも自動判定せず、辞書に登録して対応してください。
- 金額の換算は行いません。外部へ送信するのは、法人番号の確認を行う
  ときの会社名の照会だけです。
