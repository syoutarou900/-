MatchDetective - Source Code (version 1.0.0)
============================================================
This ZIP contains the full source code of MatchDetective, published so that
anyone can inspect what the app does, or build it themselves.
マルウェアやスパイウェアの類は含まれていません。中身を自由にご確認ください。


- Python 3.11 or later
- pip install -r requirements.txt


- Windows: Start-MatchDetective.bat (or: python app.py)
- Mac: Start-MatchDetective.command (or: python3 app.py)


- Windows (.exe): MakeExe-*.bat (uses PyInstaller) — if included
- Mac (.app): MakeApp-Mac.command

Notes:
法人番号検索を使う場合は、国税庁の無料API IDをご自身で取得し、設定画面で入力してください（ID自体はソースに含まれていません）。
To use the corporate-number lookup, obtain a free API ID from the National Tax Agency (Japan) and enter it in the settings (no ID is included in the source).
