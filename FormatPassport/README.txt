フォーマットパスポート（FormatPassport）
========================================

海外から届いた Excel / CSV が、日本で開くと壊れる——
日付がずれる、金額の桁が変わる、列がずれる。
逆に、日本のファイル（全角数字・和暦）が海外のシステムに入らない。
このアプリは、送り手の国と受け手の国を選ぶだけで、
形式の違いを変換候補として用意し、変換前／変換後を並べて見せます。


2通りに読める値（例：03/04 は3月4日か4月3日か）は、
アプリが勝手に決めません。「要確認リスト」に入り、
人間が選ぶまで元のまま出力され、レポートに件数が残ります。


- CSV / Excel(.xlsx) をドラッグ＆ドロップ（元ファイルは変更しません）
- 190か国の国別形式データ（通貨・日付順・小数点・区切り文字）を内蔵
- 日付：国別順序で解釈し受け手の形式へ。列内の明白な値（25/03など）が
列の形式を証明できれば、それに従います
- 金額・数値：小数点カンマ⇔ピリオド、桁区切り（./,/空白/'）、全角→半角
- 和暦⇄西暦（令和・平成・昭和・大正・明治、元年対応、R8.11.13 形式も可）
- コード列（007 など）は文字列として保護し、数値変換しません
- CSV：区切り文字の検出（カンマ/セミコロン/タブ/パイプ）、
文字コード検出（UTF-8 BOM有無 / Shift_JIS / Latin-1）、
出力は受け手の区切り文字＋文字コード選択（UTF-8 BOM 既定）
- 為替換算（金額列のみ、既定オフ）：
・試算モード：中央銀行などの公式レートを優先する階層方式
Tier1＝各国中央銀行の公式発表（米FRB/H.10(FRED)、豪RBA、
ポーランドNBP、チェコCNB、ウクライナNBU、ノルウェー中銀、
香港HKMA、ブラジルBCB/PTAX）
Tier2＝ECB基準レート（Frankfurter経由）
Tier3＝ExchangeRate-API 集計値（公式が無い通貨のみの最終手段）
使用した出典と「最も低いティア」がラベルに必ず表示されます。
試算は実際の送金・決済額ではありません。
・銀行レートモード（円ペア）：三菱UFJ銀行の公示TTS/TTBを自動取得
（対象9通貨）。外貨→円はTTB、円→外貨はTTS。手数料は含みません。
・手入力モード：任意の銀行のTTS/TTBまたは単一レートを入力可能
- レートは起動時＋「レート更新」で取得し、%APPDATA%\FormatPassport
（Macでは ~/Library/Application Support/FormatPassport）に
日付・出典つきでキャッシュ。オフライン時はキャッシュ＋古さ表示。
- UIは13言語（日本語・English・Español・简体中文・Français・Deutsch・
Português・Русский・Italiano・Türkçe・العربية(RTL)・Bahasa Indonesia・한국어）


【Windows】
1. Start-FormatPassport.bat をダブルクリック（ソース版）
または FormatPassport.exe（EXE版フォルダ内）
2. 送り手の国・受け手の国を選ぶ
3. ファイルをドロップ → 変換プレビューを確認
4. 要確認リストがあればダブルクリックして候補を選ぶ
5. 「CSVで保存」または「Excelで保存」で新しいファイルに出力

【Mac（macOS 11 以降）】
ソース版ZIPには Mac 用スクリプトが同梱されています。
・すぐ試す場合：Start-FormatPassport.command をダブルクリック。
  初回は自動で Python 環境（.venv）を作り、必要なライブラリを
  入れてから起動します。Python 3 が無い Mac では、入手方法を
  表示して終了します（https://www.python.org/downloads/macos/）。
・アプリとして使う場合：MakeApp-Mac.command をダブルクリック
  すると、dist フォルダに FormatPassport.app が生成されます。
  まず両対応の universal2（Apple Silicon ＋ Intel）で生成を
  試み、失敗した場合はその Mac のチップ専用で再試行します。
  どちらで作れたかは最後に画面表示されます。
・生成された .app は未署名のため、初回はダブルクリックでは
  開けないことがあります。右クリック（Control＋クリック）→
  「開く」で起動してください。
・設定と為替キャッシュは ~/Library/Application Support/
  FormatPassport に保存されます。
・Mac 実機での動作は未検証です（Mac が無い開発環境のため、
  コードの OS 分岐とスクリプトの動作条件のみ確認しています）。


- 実際のWindows環境での動作は未検証です（開発環境でのテスト＋
Wine互換レイヤーでの起動確認のみ）。不具合報告は出典・レート日付が
表示されるレポートと一緒にいただけると助かります。
- 為替の試算モードは基準レートによる概算です。実際の送金額・決済額は
銀行の適用レート（TTS/TTB）と手数料で決まります。
-.xls（旧形式）・マクロ付きブックのマクロは扱いません。

Python / PySide6。テストは tests/ にあります（ネット不使用）。
