DropLauncher - Source Code (version 1.0.0)
============================================================
This ZIP contains the full source code of DropLauncher, published so that
anyone can inspect what the app does, or build it themselves.
マルウェアやスパイウェアの類は含まれていません。中身を自由にご確認ください。


- Python 3.11 or later
- pip install -r requirements.txt


- Windows: Start-DropLauncher.bat (or: python app.py)
- Mac: Start-DropLauncher.command (or: python3 app.py)


- Windows (.exe): MakeExe-*.bat (uses PyInstaller) — if included
- Mac (.app): MakeApp-Mac.command
