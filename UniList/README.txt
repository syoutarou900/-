================================================================
UniList（ユニリスト） v1.0.0
顧客・取引先リストの重複を、人が確認しながら1件にまとめるアプリ
================================================================

■ このアプリがすること
顧客・取引先リスト（CSV／Excel）を読み込むと、国ごとの表記ルールで
名前・電話・メール・住所・IDを正規化し、「重複らしいグループ」を
候補として提示します。左右比較のプレビューで項目ごとに
「どちらの値を残すか」を選んで統合できます。

■ 大切な約束
・統合するのは、人が承認したグループだけです。
アプリが勝手に消すことはありません。
・元ファイルは一切変更しません。結果は新しいファイルに書き出します。
・統合はいつでも取り消せます。統合ログとセッション保存で、
いつでも元に戻せる記録が残ります。
・候補の判定に「あいまいな照合（類似度・ファジー）」は使いません。
正規化した結果が完全に一致したものだけが候補になります。
・「重複ではない」と判断したペアは記録され、次回読み込み時も
候補に出なくなります。
・オフラインで動作します。外部への送信・連携はありません。

■ 候補の段位（確からしさは類似度ではなく決定的な段位で表示）
A：名前が一致し、電話・メール・住所のいずれかも一致（強い候補）
B：名前のみ一致
C：電話・メール・IDのいずれかが一致するが名前は一致しない
（社名変更などの可能性があるため、理由を明示して弱い候補として表示）
各候補には「どの項目が完全一致したか」が必ず表示されます。

================================================================
■ Windows（EXE版）の使い方
================================================================
※EXE版は 64ビット（x64）向けです。Windows 10／11 の64ビット版で
  お使いください。
1. UniList-Windows.zip をダウンロードして展開します。
2. フォルダの中の UniList.exe をダブルクリックします。
※フォルダごと使う形です。EXEだけを外に出すと動きません。
※署名のないアプリのため、初回起動時にWindowsの保護
（SmartScreen）の警告が出る場合があります。その場合は
「詳細情報」→「実行」の順に進んでください。

■ Windows（ソース版）の使い方
1. UniList-Source.zip を展開します。
2. Start-UniList.bat をダブルクリックします。
初回だけ必要なライブラリを自動で入れます（Pythonが必要です）。

================================================================
■ Mac での使い方（ダウンロード配布の流れ）
================================================================
Mac版は「アプリ生成スクリプト」をダウンロードして、
お使いのMac上でアプリ本体を生成する形です。
対応は macOS 11（Big Sur）以降です。それより古いmacOSの
Intel Macは対象外です。
生成される .app は、実行したMacのチップに合わせて組み立てられます。
通常は Apple Silicon と Intel の両方で動く universal2 版ができ、
環境によってはそのMac専用（Apple Silicon機ならarm64、
Intel機ならx86_64）の版になります。どちらで作れたかは、
生成スクリプトの最後に画面表示されます。

1. UniList-Source.zip をダウンロードして展開します。
2. 展開したフォルダの中の「MakeApp-Mac.command」を
ダブルクリックします。
※初回だけ、macOSに止められる場合があります。その場合は
ファイルを右クリック→「開く」→「開く」で実行してください
（署名のないスクリプトのための、macOS標準の手順です）。
※Python 3 が無いMacでは、スクリプトが検出して入手方法
（python.org のインストーラ／Homebrew／Xcodeコマンドライン
ツール）を画面に表示します。入れた後、もう一度ダブルクリック
してください。
3. 生成が終わると、同じフォルダの「dist」の中に
「UniList.app」ができます。
4. 以後は UniList.app をダブルクリックして使います。
※.app も署名がないため、初回起動時だけ右クリック→「開く」
が必要です。

ソースから直接起動したい場合は「Start-UniList.command」
でも起動できます（初回は環境を自動で用意します）。

Mac版は、開発側にMac実機がないため実機未検証です。
Windows版と同じソースコード（Python＋PySide6）で動作する設計で、
.app はお使いのMac上で上記スクリプトが生成します。

================================================================
■ 使い方の流れ（共通）
================================================================
1. リストを開く（CSV／TSV／xlsx／txt。文字コードと区切り文字は自動判定）
2. 「列の役割」を確認する（アプリが推定して提示します。
違っていたら画面で直せます。直接文字を打って修正しても、
全角・半角や同義語のゆれは自動で吸収します）
3. 「重複候補を探す」を押す
4. 候補グループを選ぶと左右比較のプレビューが出ます。
項目ごとに残す値を選んでください
5. 「このグループを統合する」を押したグループだけが統合されます
6. 統合済みリストを新しいファイルに書き出します

================================================================
■ 制限
================================================================
・名前の正規化は表記ルールに基づく決定的な処理です。
漢数字の住所番地や、読みが全く異なる略称までは同一と判定しません
（違う相手を候補に出さないための設計です）。
・電話番号は国番号と国内の「0」をそろえて比較します。
・大きなリスト（5万行程度）でも実用速度で動作します。

================================================================
English summary
================================================================
UniList merges duplicate customers/vendors
in a CSV/Excel list into one record. Candidates are EXACT matches
after deterministic normalization only - no fuzzy/similarity
matching. A human approves each group in a side-by-side preview,
choosing the value to keep per field. The original file is never
modified, merges can be undone, and pairs marked "not duplicates"
are remembered. Windows: run UniList.exe (64-bit x64) from
the extracted folder. macOS 11 (Big Sur) or later: extract
UniList-Source.zip, double-click MakeApp-Mac.command
(right-click -> Open the first time), and it builds
dist/UniList.app on your Mac - universal2 when possible,
otherwise native to your Mac's chip (older macOS on Intel Macs is
not supported). The macOS build has not been verified on a real
Mac (no Mac was available to the developer).
