# Kode Sumber

Folder ini berisi **kode sumber lengkap** dari seluruh 13 aplikasi yang
diterbitkan di situs distribusi. Setiap aplikasi memiliki foldernya sendiri
yang berisi seluruh kode sumbernya. Anda dapat menelusuri dan membaca
berkas-berkasnya langsung di GitHub, tanpa mengunduh apa pun.

## Lisensi

Seluruh kode sumber di sini dirilis di bawah **Lisensi MIT**.
Lihat berkas `LICENSE` di akar repositori ini.

## Unduhan ZIP

Kode sumber yang sama juga tersedia sebagai berkas ZIP (`<App>-Source.zip`),
yang dilampirkan pada Release GitHub setiap aplikasi, jika Anda lebih menyukai satu kali unduhan.
