# Codice sorgente

Questa cartella contiene il **codice sorgente completo** di tutte le 13 app
pubblicate sul sito di distribuzione. Ogni app ha la propria cartella con
l'intero codice sorgente. Puoi sfogliare e leggere i file direttamente qui su
GitHub, senza scaricare nulla.

Vedi il file `LICENSE` nella radice di questo repository.
