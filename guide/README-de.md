# Quellcode

Dieser Ordner enthält den **vollständigen Quellcode** aller 13 Apps, die auf der
Download-Website veröffentlicht sind. Jede App hat ihren eigenen Ordner mit dem
kompletten Quellcode. Sie können die Dateien direkt hier auf GitHub ansehen und
lesen, ohne etwas herunterzuladen.

## Lizenz

Der gesamte hier veröffentlichte Quellcode steht unter der **MIT-Lizenz**.
Maßgeblich ist die Datei `LICENSE` im Stammverzeichnis dieses Repositorys.
