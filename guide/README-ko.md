# 소스 코드

이 폴더에는 배포 사이트에 공개된 자작 앱 13개 전부의 **소스 코드 일체**가 들어
있습니다. 각 앱마다 전용 폴더가 있으며, 그 안에 해당 앱의 소스 코드가 그대로
들어 있습니다. GitHub 화면에서 파일을 클릭하면 다운로드하지 않고도 내용을
읽을 수 있습니다.

## 라이선스

여기에 있는 모든 소스 코드는 **MIT 라이선스**로 공개됩니다.
라이선스 본문은 이 저장소 최상위에 있는 `LICENSE` 파일이 적용됩니다.

## ZIP 버전 안내

같은 소스 코드는 ZIP 형식(`<앱 이름>-Source.zip`)으로도 배포하고 있습니다.
ZIP 버전은 각 앱의 GitHub 릴리스에 첨부되어 있으니, 한 번에 다운로드하고 싶을 때는 그쪽을 이용해 주세요.
