# Kaynak Kodu

Bu klasör, dağıtım sitesinde yayımlanan 13 uygulamanın tamamının **kaynak
kodunu** içerir. Her uygulamanın, kaynak kodunun tamamını barındıran kendi
klasörü vardır. Dosyaları hiçbir şey indirmeden, doğrudan GitHub üzerinde
inceleyip okuyabilirsiniz.

## Lisans

Buradaki tüm kaynak kodu **MIT Lisansı** ile yayımlanmaktadır.
Bu deponun kök dizinindeki `LICENSE` dosyasına bakın.

## ZIP indirmeleri

Aynı kaynak kodu, tek seferde indirmeyi tercih ederseniz, her uygulamanın GitHub Release sayfasına eklenmiş ZIP dosyaları (`<App>-Source.zip`) olarak da sunulmaktadır.
