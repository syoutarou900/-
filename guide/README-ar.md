# كود المصدر

يحتوي هذا المجلد على **كود المصدر الكامل** لجميع التطبيقات الثلاثة عشر المنشورة
على موقع التوزيع. لكل تطبيق مجلده الخاص الذي يضم كود المصدر كاملًا.
يمكنك تصفح الملفات وقراءتها هنا على GitHub مباشرة دون تنزيل أي شيء.

## الترخيص

يُنشر كل كود المصدر هنا بموجب **ترخيص MIT**.
راجع ملف `LICENSE` الموجود في جذر هذا المستودع.
