# ソースコード置き場

ここは、配布サイトで公開している自作アプリ（全13本）の**ソースコード置き場**です。
各アプリのフォルダの中に、そのアプリのソースコード一式がそのまま入っています。
GitHubの画面上でファイルをクリックすれば、ダウンロードしなくても中身を読むことができます。

## ライセンス

全アプリのソースコードは **MITライセンス** です。
ライセンス本文は、このリポジトリの直下にある `LICENSE` ファイルが適用されます。

## ZIP版について

同じソースコードは、ZIP形式（`<アプリ名>-Source.zip`）でも配布しています。
ZIP版は、各アプリのGitHubリリースに添付されていますので、まとめてダウンロードしたい場合はそちらをご利用ください。
