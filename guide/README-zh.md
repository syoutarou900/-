# 源代码

此文件夹包含分发网站上发布的全部 13 款应用的**完整源代码**。
每款应用都有自己的文件夹，里面是该应用的全部源代码。
您可以在 GitHub 页面上直接点击文件浏览和阅读内容，无需下载。

## 许可证

这里的全部源代码均以 **MIT 许可证**发布。
许可证全文适用于本仓库根目录下的 `LICENSE` 文件。
