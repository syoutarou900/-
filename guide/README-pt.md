# Código-fonte

Esta pasta contém o **código-fonte completo** de todos os 13 aplicativos
publicados no site de distribuição. Cada aplicativo tem sua própria pasta com
todo o seu código-fonte. Você pode navegar e ler os arquivos diretamente aqui
no GitHub, sem baixar nada.

## Licença

Todo o código-fonte aqui publicado é disponibilizado sob a **licença MIT**.
Consulte o arquivo `LICENSE` na raiz deste repositório.
