# Código fuente

Esta carpeta contiene el **código fuente completo** de las 13 aplicaciones
publicadas en el sitio de distribución. Cada aplicación tiene su propia carpeta
con todo su código fuente. Puedes explorar y leer los archivos directamente
aquí en GitHub, sin descargar nada.

## Licencia

Todo el código fuente aquí publicado se ofrece bajo la **licencia MIT**.
Consulta el archivo `LICENSE` en la raíz de este repositorio.
