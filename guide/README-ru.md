# Исходный код

В этой папке находится **полный исходный код** всех 13 приложений,
опубликованных на сайте распространения. У каждого приложения своя папка со
всем его исходным кодом. Файлы можно просматривать и читать прямо здесь, на
GitHub, ничего не скачивая.

## Лицензия

Весь исходный код здесь распространяется по **лицензии MIT**.
Текст лицензии — в файле `LICENSE` в корне этого репозитория.
