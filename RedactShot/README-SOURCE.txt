RedactShot - Source Code (version 1.0.0)
============================================================
This ZIP contains the full source code of RedactShot, published so that
anyone can inspect what the app does, or build it themselves.
マルウェアやスパイウェアの類は含まれていません。中身を自由にご確認ください。


- Python 3.11 or later
- pip install -r requirements.txt


- Windows: Start-RedactShot.bat (or: python app.py)
- Mac: Start-RedactShot.command (or: python3 app.py)


- Windows (.exe): MakeExe-*.bat (uses PyInstaller) — if included
- Mac (.app): MakeApp-Mac.command

Notes:
OCR機能にはTesseract（別途インストール）が必要です。配布中のアプリ版には同梱済みです。
The OCR features require Tesseract (installed separately). The distributed app builds include it.
