PurePaste　使い方
================================

コピーした瞬間に、クリップボードの中のテキストを自動で綺麗に整形する
Windows用の常駐アプリです。


・変な改行を取る … PDFやWebで文の途中で切れた改行をつなげます
　（段落の区切り＝空行、箇条書きは残します）
・連続スペース・タブを1つに
・行頭・行末のスペースを取る
・全角の英数字を半角に（Ｔｅｓｔ１２３ → Test123）
・半角カナを全角カナに（ｱｲｳ → アイウ）
・全角スペースを半角スペースに
・日本語の間のスペースを取る（こ ん に ち は → こんにちは）
・空行が続いたら1行にまとめる


1. PurePaste.exe をダブルクリック
2. 設定画面が開きます。そのままコピー作業をすれば自動で整形されます
3. ウィンドウを閉じてもアプリは終わりません。
　画面右下のタスクトレイ（時計の近く）に青い「P」アイコンで常駐します
4. 完全に終わらせる：トレイのアイコンを右クリック →「終了」


1. ZIPを右クリック →「すべて展開」
2. 展開したフォルダの Start-PurePaste.bat をダブルクリック
3. 初回だけ部品（約120MB）を自動でダウンロードします。
　黒い画面は閉じずに待ってください（アプリ使用中はずっと開いたまま）


・整形を止めたい → 設定画面の大きなボタンでOFF、またはトレイ右クリック「一時停止 / 再開」
・元の文に戻したい → トレイ右クリック「直前の元のテキストに戻す」
　そのあと貼り直してください
・設定は自動で保存されます（%APPDATA%\PurePaste\settings.json）
・Windows起動時に自動で始めたい → 設定の
　「Windowsを起動したら自動でこのアプリも始める」にチェック


・画像やファイルのコピーには何もしません（テキストだけを整形します）
・パスワードなど、コピーした文字はすべて整形対象です。
　整えたくないときは一時停止してください
・実物のWindows PCでの起動確認は未実施です（テスト環境で確認済み）


Mac版について
================================

同じプログラムで、Macでも使えます（ソース版／.app化）。
対応環境は macOS 11（Big Sur）以降です。

【ソースのまま使う】
1. ZIPを展開する
2. Start-PurePaste.command をダブルクリック
　（未署名のためブロックされたら、右クリック →「開く」）
3. 初回だけ、部品を自動でダウンロードします
4. Python 3 が無いMacでは、画面の案内（python.org）から
　先に入れてください

【アプリ（.app）にして使う】
1. ZIPを展開する
2. MakeApp-Mac.command をダブルクリック
3. dist フォルダに PurePaste.app ができます
　初回起動時は右クリック →「開く」で開いてください
・チップ（CPU）について：まず Apple シリコン／Intel 両対応の
　「universal2」版を作ろうとし、作れない場合は、
　そのMacのチップ専用版を自動で作ります（画面に表示されます）

【Windows版と違う点（正直なお知らせ）】
・常駐先はタスクトレイではなく、画面上部のメニューバーです。
　ウィンドウを閉じても常駐は続き、終了はメニューバーの
　アイコンの右クリック →「終了」です
・設定の保存先は ~/Library/Application Support/PurePaste の
　settings.json です
・設定画面の「Windowsを起動したら自動で始める」チェックは
　Macでは効きません。Macでログイン時に自動で始めたい場合は、
　システム設定 → 一般 → ログイン項目 に PurePaste.app を
　追加してください。（上級者向け：~/Library/LaunchAgents に
　PurePaste.app を指す LaunchAgent の plist を置いても同じです）
・クリップボード監視と整形の仕組みは Windows版とまったく同じ
　プログラムです
・Macの実機での動作確認は未実施です（開発環境にMacが無いため。
　初めて使う方の環境で .app を生成する方式です）
